متجر فساتين أطفال وملابس بيبي إسبانية: واجهة متجر للزبونات + لوحة إدارة، بنفس أسلوب عمل [ملائم](https://github.com/mohammedalseari-design/mulaem-dash):
ملفات ثابتة على **GitHub Pages**، وقاعدة البيانات والصلاحيات والتخزين على **Supabase** (مشروع «بيلا روزا»، `oxsttfljqbunanmwdzft`، منظمة mulaem).

## المبدأ

كل التحقق والحسابات المالية في السيرفر، والمتصفح لا يُصدَّق:

- الزائرة تقرأ الكتالوج فقط (RLS)، وتُنشئ الطلب عبر الدالة `place_order` التي تحسب الأسعار والشحن والضريبة من قاعدة البيانات لا من السلة المرسلة، وتقفل المخزون وتحجزه.
- الموظفة تدير المنتجات والطلبات من اللوحة، ولا تستطيع تغيير مبالغ طلب قائم (حارس في قاعدة البيانات)، والإلغاء يرجع المخزون تلقائياً ويُسجَّل.
- الأسعار شاملة ضريبة القيمة المضافة (15٪)، وتُحفظ قيمة الضريبة مع كل طلب للفاتورة.

|---|---|

| `js/config.js` | رابط المشروع والمفتاح العام (آمن للنشر). **لا يوضع فيه مفتاح الخدمة أبداً** |
| `supabase/migrations/` | الجداول + الدوال + المشغّلات + RLS + مخزن الصور (طُبّقت على المشروع الحي عبر Supabase MCP) |

| `scripts/add-staff.sql` | إضافة موظفة/مدير بكلمة مرور مؤقتة تُجبر على تغييرها عند أول دخول (وحظر/إعادة تعيين) |
| `tests/db.test.sql` | 22 اختباراً لقاعدة البيانات: الصلاحيات، إنشاء الطلب، المبالغ، الإلغاء، التلاعب، كلمة المرور المؤقتة |
| `tests/e2e/` | 27 اختبار متصفح (Playwright) للمتجر واللوحة والدفع على محاكاة محلية لـ Supabase |
| `.github/workflows/keepalive.yml` | نبضة يومية تمنع إيقاف المشروع المجاني |
| `.github/workflows/backup.yml` | نسخة احتياطية ليلية (تحتاج السر `SUPABASE_DB_URL` — انظر `docs/BACKUP.md`) |
| `docs/` | خارطة التطوير، ملفات المهام لكل مرحلة، الإعداد، النطاق، النسخ الاحتياطي |
| `shopify/theme/` | ملفات الثيم العربي «Horizon — بيلا روزا (عربي)» كما رُفعت إلى Shopify (الإعدادات، الهيدر، التذييل، الرئيسية) |

## الاختبارات

- قاعدة البيانات: نفّذ `tests/db.test.sql` في SQL Editor (أو عبر Supabase MCP) بعد `scripts/seed-demo.sql` — ينشئ موظفاً وطلبات وهمية ويحذفها.
- المتصفح: `npm install` ثم `npm test` — يشغّل خادماً محلياً ومحاكاة لـ Supabase ويجرّب رحلة الشراء كاملة ولوحة الإدارة.
