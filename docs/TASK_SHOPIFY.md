## الثيم العربي (أُعيد بناؤه 23 سبتمبر مساءً)

نسخة Horizon باسم «Horizon — بيلا روزا (عربي)» (`gid://shopify/OnlineStoreTheme/192364740889`)، غير منشورة لأن الـ API يمنع
نشر الثيمات (تُنشر بضغطة من Online Store → Themes). ملفاتها الأربعة محفوظة في `shopify/theme/` بالمستودع
(نُسخ حرفية لما رُفع — تُرفع عبر `themeFilesUpsert`):

- `config/settings_data.json`: الخطوط Almarai (النصوص) وAmiri (العناوين)، اللوحة عاجي `#FBF7F4` / برقوقي `#5B2A3C` /
  وردي `#E8D3D7`، عرض الصفحة عادي، بطاقات بزوايا ناعمة وتكبير خفيف عند المرور.
- `sections/header-group.json`: شريط إعلانات بثلاث رسائل (توصيل لكل المملكة، استلام من المحل بجدة، استبدال خلال 3 أيام)
  + الهيدر بالشعار والقائمة الرئيسية.
- `sections/footer-group.json`: نبذة + روابط المجموعات + الصفحات + اشتراك بريدي + حقوق.
- `templates/index.json` (الرئيسية، 9 أقسام بالترتيب): غلاف كامل العرض (يحتاج صورة) → شريط ثقة متحرك → «تسوّقي حسب الفئة»
  (4 بطاقات) → «مختارات بيلا روزا» (8 منتجات) → «قصتنا» (بطاقة وردية + زر «تعرّفي علينا» → `/pages/about`) →
  «ملابس بيبي (0–24 شهر)» → «لماذا بيلا روزا؟» (4 بطاقات: خامات إسبانية، مقاسات بالأعمار، استبدال 3 أيام، دفع مريح) →
  أسئلة شائعة (أكورديون: المقاس، التوصيل، الاستلام، الاستبدال) → اشتراك بريدي.

التحقق: فُحصت الملفات الأربعة ضد مخططات (schemas) أقسام Horizon وكتله (1,616 إعداداً: المعرّفات، الخيارات، المدى) بلا
أخطاء، وتطابق md5 الملف المرفوع مع المحلي. لم تُعاين بصرياً لأن المتجر محمي بكلمة مرور والمعاينة تتطلب دخول الإدارة —
تُعاين من Customize قبل النشر.

## ما يحتاج يد صاحب المتجر — 7 خطوات للإطلاق (بالترتيب، من تطبيق Shopify أو المتصفح)

كل ما يمكن عمله عبر الـ API نُفِّذ؛ الباقي إعدادات لا يتيحها الـ API أو تتطلب حسابه وبياناته:

1. **الاشتراك وفتح المتجر**: اختيار خطة Basic، ثم Online Store → Preferences → إلغاء حماية كلمة المرور. بعدها أبلغني
   لأفعّل تحويل الموقع القديم (`SHOP_REDIRECT` في `js/config.js`).
2. **الاسم واللغة**: Settings → Store details → «بيلا روزا» + الجوال والبريد؛ Settings → Languages → العربية → «تعيين
   كلغة افتراضية».
3. **نشر الثيم**: Online Store → Themes → «Horizon — بيلا روزا (عربي)» → Customize للمعاينة ورفع الشعار وصورة الغلاف
   (قسم Hero) ثم Publish.
4. **الدفع**: Settings → Payments → Manual payment methods: «الدفع عند الاستلام» و«التحويل البنكي» (بتعليمات الآيبان)؛
   ثم تثبيت تطبيق **Moyasar** وربطه بحسابه التجاري (مدى، فيزا/ماستر، Apple Pay، STC Pay). لاحقاً تابي وتمارا.
5. **الضريبة والسياسات**: Settings → Taxes and duties → Saudi Arabia → 15٪ (الأسعار شاملة الضريبة مفعّلة أصلاً)؛
   Settings → Policies → لصق النصوص من `docs/SHOPIFY_POLICIES.md`.
6. **المحل والقنوات**: تطبيق Shopify POS على جوال/تابلت المحل بنفس الحساب (الموقع «بيلا روزا — المحل» جاهز)؛ قنوات
   Facebook & Instagram وTikTok وSnapchat — كل واحدة تفويض بحسابه.
7. **المنتجات الحقيقية** بصورها (من تطبيق Shopify مباشرة)، وحذف الثمانية التجريبية أو استبدال محتواها.

لاحقاً: النطاق الخاص عند شرائه يُربط من Settings → Domains.

## اختبار القبول

1. طلب تجريبي كامل من الجوال (منتج بمقاس ولون → السلة → الدفع عند الاستلام) يظهر في طلبات Shopify بالمبلغ والشحن الصحيحين.
2. رابط الموقع القديم يفتح متجر Shopify مباشرة (بعد تفعيل `SHOP_REDIRECT`).
3. بعد ربط Moyasar: دفع ببطاقة اختبار يكتمل، ويظهر الطلب «مدفوع».

## ما يتوقف

- لوحة الإدارة الحالية ودالة `place_order` تبقيان بلا استخدام؛ لا تُحذفان قبل اكتمال شهر تشغيل على Shopify.
- النسخ الاحتياطي الليلي لـ Supabase يصبح غير ضروري (Shopify يحفظ بياناته)؛ يُترك كما هو أو يُعطَّل.
- بوابة Moyasar بالكود الخاص (`moyasar-verify`) لا تُستخدم؛ تطبيق Moyasar داخل Shopify يحل محلها.
